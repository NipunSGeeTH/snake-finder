# How to read a result

The app shows a name, a scientific name, and a percentage. The percentage is how strongly the selected model preferred that name. It is not a proof.

## One name

A single name means the snake check passed and the selected model had a leading class. Look at the other scores under it. If they are close, treat the result as a short list, not a fact.

## Not a snake

If the first check does not see a snake, no species name is shown. That is deliberate. The wide catalog would otherwise invent a species for a phone, a flower, or a drawing.

## Low confidence

Under about 55 percent, the result is marked uncertain. Compare the head, the eyes, and the scale pattern with the field guide before you accept the name.
